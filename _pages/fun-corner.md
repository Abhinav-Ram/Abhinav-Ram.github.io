## Games
As a hobby, I like to play computer games as well (Common hobby, I know)... that I created myself. A lot of these are vibe coded though, but the ideas and creativity are all mine.

- [Kaasu, Panam, Dhuddu, Money Money!](https://github.com/Abhinav-Ram/Kaasu-Panam-Dhuddu-Money-Money) is a Tamil Nadu themed digital monopoly game made to be setup and played locally by multiple players on the same computer. It is specifically deigned to feel almost like real monopoly with payments, dice moves, and the board design. So the game moves explicitly slow but with an authentic experience.

- [Frontline Duel](https://github.com/Abhinav-Ram/FrontlineDuel) is a gritty two-player local multiplayer shooter with a battle/duel theme. It is also made to be setup and played locally by 2-players. Try different weapons and gamemodes!

- [Uno Terminal](https://github.com/Abhinav-Ram/uno-card-game) as the name suggests, is a terminal version of the classic UNO game.

- [UKK Memory Game](https://abhinav-ram.github.io/ukk-memory-game/) is a small Match-the-Tiles based game themed around dishes in my "Uppu Konjam Kammi" page mentioned above.
